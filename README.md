# Gerenciador de Produtos com Árvore Binária (BST em C)

Projeto desenvolvido durante a faculdade de Computação para praticar Estruturas de Dados e alocação dinâmica de memória.

--- Funcionalidades
- **Inserção:** Adiciona novos produtos ordenados por código usando uma Árvore Binária de Busca.
- **Busca:** Localiza produtos rapidamente pelo código.
- **Listagem:** Exibe todos os produtos em ordem crescente de código.
- **Estatísticas:** Identifica automaticamente o produto mais caro e o mais barato da árvore.
- **Gestão de Memória:** Limpa e desaloca todos os nós da memória ao encerrar o programa (`free`).

Tecnologias
- Linguagem C
--- Como compilar e executar
Certifique-se de ter um compilador C instalado (como o GCC) e execute os comandos no terminal:

```bash
# Compilar
gcc main.c -o programa

# Executar
./programa
